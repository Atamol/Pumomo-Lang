# Pumomo Lang

ガバ穴ダディーの語録で書くプログラミング言語．予約語，組み込み関数などもすべてはガバ穴ダディーに通ずる．

```
ぷももえんぐえげぎおんもえちょっちょっちゃっさっ！

緩次郎 ガバ穴ダディー()
    最高出力を 「ぷもも園へようこそ」
ムッキュ
```

## Hello, World!

```
ぷももえんぐえげぎおんもえちょっちょっちゃっさっ！

緩次郎 ガバ穴ダディー()
    最高出力を 「Hello, World!」
ムッキュ
```

17音だけでも書け，100を土台にし，`お`で複製しては差を足し引きし，`さっ`で文字コードを文字にします．

```
完全合体合金おちんちん
    ぷもももももももももも お ぐ                                        # 100
    お ぷもももももももももももももももももももももももももももも ん さっ # H
    お ぷも え さっ                                                     # e
    お ぷもももももももも え さっ                                       # l
    お ぷもももももももも え さっ                                       # l
    お ぷももももももももももも え さっ                                 # o
    ぷもももも ぷももももももももももも ぐ さっ                         # ,
    ぷもももも ぷもももももももも ぐ さっ                               # 空白
    お ぷももももももももももももも ん さっ                             # W
    お ぷももももももももももも え さっ                                 # o
    お ぷもももももももももももももも え さっ                           # r
    お ぷもももももももも え さっ                                       # l
    お さっ                                                             # d
    ぷもももも ぷもももももももも ぐ ぷも え さっ                       # !
    ちょ
ムッキュ
```

全体は`examples/hello_world.pmm`にあります．

# 動作

依存クレートはなく，リポジトリ直下にある`pmm`，`pumomo`のシムによりPATHを触らずにそのまま呼べます．

中身は`target/release/pumomo.exe`を叩くだけです．

```bash
cargo build --release
```

```bash
./pmm examples/hello.pmm
```

PowerShellかcmdでは`.\pmm examples\hello.pmm`または`pumomo`で動き，予約語と17音の一覧は`./pmm 語録`で確認できます．

## 記法

ファイルの先頭に中核フレーズを書かないと動きません．

トップレベルに置けるのは`緩次郎`による関数定義のみで，`ガバ穴ダディー`という名前の関数から始まります．

```
ぷももえんぐえげぎおんもえちょっちょっちゃっさっ！

緩次郎 ガバ穴ダディー()
    いっぱいいっぱいゆうじろう i = 1..15
        ドーラ i % 15 == 0
            最高出力を 「ぷももえん」
        銅鑼 i % 3 == 0
            最高出力を 「ぷもも」
        銅鑼 i % 5 == 0
            最高出力を 「えん」
        ドアラ
            最高出力を i
        ムッキュ
    ムッキュ
ムッキュ
```

役割は語録の意味に少し寄せてあり，例えば

- `最高...出力を...`: 出力
- `いっぱい、入っちゃう！`: 変数宣言
- `動いてる...中で...`: while
- `一緒に帰りたい...`: return
- `そこッ！`: break
- `ドーラ`: if
- `ドアラ`: else if
- `銅鑼`: else

のようになっています．

詳しくは以下を参照:

| 語録                                                                 | 役割                                 |
| -------------------------------------------------------------------- | ------------------------------------ |
| `いっぱい入っちゃう` / `おまんこロックマン`                      | 変数宣言 / 定数宣言                  |
| `最高出力を` / `豚キムチ` / `お尻の穴が`                       | 出力 / 改行なし出力 / 標準エラー出力 |
| `おちんちんくださぁい？` / `いっぱいちょうだい？`                | 1行入力 / 全部入力                   |
| `ドーラ` / `銅鑼` / `ドアラ`                                   | if / else if / else                  |
| `動いてる中で` / `いっぱいいっぱいゆうじろう`                    | while / 範囲ループ                   |
| `Delight! Beast! おまんこの中でEasy! Easy!` / `ジャッキーチェン` | 各要素ループ / 無限ループ            |
| `そこッ` / `てっ` / `一緒に帰りたい`                           | break / continue / return            |
| `ムーア我慢できぬ` / `オッパゲドン` / `ｵﾚﾓｲｯﾁｬｳ`       | assert / 終了 / 異常終了             |
| `細菌入り味噌` / `オ゛ア゛ッ゛` / `細菌入っちゃう`             | try / catch / throw                  |
| `ンキモチイイ` / `もう嫌` / `ぷもも`                           | true / false / null                  |
| `ムッキュ` / `緩次郎`                                            | ブロックの終わり / 関数定義          |

## 表記揺れ

語録は書き起こしであるため表記が定まりませんが，処理系が吸収するので大百科の表記をそのまま貼っても動きます．

半角カナ，濁点の有無，語尾の`↑`や`～`，`...`の飾り，同じ語の連呼は，どれも正式表記と同じ語として読みます．

```
ぷももえんぐえげぎぎおんもえちょっちょちゃっさっ!

緩次郎 ガバ穴ダディー()
    いっぱい、入っちゃう！ n = 1
    動いてる...中で... n < 4
        最高...出力を... n
        n = n + 1
    ムッキュッ!
    ジャッキーチェン！ジャッキーチェン！
        そこッ！
    ムッキュ
    ムーア！我慢できぬ ﾆﾝﾆﾝﾆﾝﾆﾝﾆﾝ(12407) == 「ぷ」
    一緒に帰りたい...
ムッキュ
```

## 完全合体合金おちんちん

`完全合体合金おちんちん`から`ムッキュ`までは，中核フレーズの17音だけで書くスタックマシンとなっています．

これは式として評価され，値を返し，構造化層のどこにでも埋め込めます．

```
いっぱい入っちゃう x = 完全合体合金おちんちん ぷももももも お ぐ ムッキュ
最高出力を x    # 25
```

`ぷ`に続く`も`の数がそのまま値になり，`え`，`ん`，`ぐ`，`げ`，`ぎ`，が四則と剰余，`お`，`ちょ`，`ちゃ`がスタック操作，`さ`，`さっ`が出力，`ちょっ`，`ちゃっ`がループです．

例えば，

```
完全合体合金おちんちん ぷももももも ちょっ お さ ぷも ん ちゃっ ちょ ムッキュ
```

とすると`54321`を表現できます．

## サンプル

| ファイル                     | 内容                                         |
| ---------------------------- | -------------------------------------------- |
| `examples/hello.pmm`       | 最小のプログラム                             |
| `examples/hello_world.pmm` | 17音だけの Hello, World!                     |
| `examples/fizzbuzz.pmm`    | 条件分岐と繰り返し                           |
| `examples/fib.pmm`         | 再帰とガバ穴 (配列)                          |
| `examples/goroku.pmm`      | 定数，各要素ループ，無限ループ，組み込み関数 |
| `examples/gattai.pmm`      | 低レベル層                                   |
| `examples/saikin.pmm`      | 例外と異常終了                               |
| `examples/kudasai.pmm`     | 標準入力                                     |

## その他

| コマンド                  | 内容                   |
| ------------------------- | ---------------------- |
| `./pmm <file>`          | 走らせる               |
| `./pmm --tokens <file>` | 字句 (トークン) を出力 |
| `./pmm --ast <file>`    | 構文木                 |
| `./pmm 語録`            | 予約語と17音の一覧     |
